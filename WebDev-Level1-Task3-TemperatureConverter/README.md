# Temperature Converter (OIBSIP Web Development, Level 1, Task 3)

An interactive web tool that converts a temperature between Celsius, Fahrenheit and Kelvin.

## Features
- Numeric input with validation (non-numeric input shows an error message)
- Unit selector for the input unit (Celsius, Fahrenheit, Kelvin)
- Convert button; all three units are shown at once in the result area
- Absolute zero check with a friendly message (below -273.15 °C, -459.67 °F or 0 K)
- Clean, centred, responsive layout

## Formulas
- Celsius to Fahrenheit: multiply by 9/5, add 32
- Fahrenheit to Celsius: subtract 32, multiply by 5/9
- Celsius to Kelvin: add 273.15

## Tech used
HTML5, CSS3, vanilla JavaScript

## Run it
Open `index.html` in a browser.
