# Landing Page (OIBSIP Web Development, Level 1, Task 1)

A static landing page for a freelance web developer, built with HTML5 and CSS3 only (no JavaScript).

## Features
- Sticky navigation bar with 3 links
- Hero section with headline, subheadline and call-to-action button
- Two content sections: Services and About
- Footer with placeholder contact and social links
- Single colour palette, responsive layout (Flexbox and Grid), deliberate spacing

## Run it
Open `index.html` in any browser.
